## 3. 確認

- [x] 3.1 `npm run lint` と `npm run build` がエラーなしで通ることを確かめる
- [x] 3.2 Supabase Local で、オーナーとして設定画面から名前を変え、設定画面、サイドバー、スマホのヘッダー、切り替えの一覧に新しい名前が出ること、再読み込みしても新しい名前であること、キャンセルで元のままであること、空の名前は保存されないことを確かめる
  - 確認結果: 自動で確かめた（利用者と相談して決定）。テスト用のセッションで DevTools Protocol を操作した。オーナーには鉛筆のボタンが出て、押すと今の名前が入った入力欄にフォーカスが移り「11 / 50」が出る。名前を変えて Esc で元のまま（DB も変わらない）。空白だけで保存を押すと「レシピノートの名前を入力してください。」が出て DB は変わらない。「  我が家のレシピ  」で Enter を押すと、設定画面の見出し、スマホのヘッダー、切り替えの一覧、PC のサイドバーが「我が家のレシピ」になり、DB も前後の空白なしで保存され、再読み込みしても新しい名前のまま
  - 追記: 利用者の確認で、日本語の変換を確定する Enter で保存される不具合が見つかった。変換中の Enter と Esc を無視するよう直し、`isComposing: true` の Enter、`keyCode` 229 の Enter、変換中の Esc では編集が続き DB が変わらないこと、通常の Enter で保存されることを DevTools Protocol で確かめた
- [x] 3.3 Supabase Local で、オーナーでないメンバーの設定画面に「名前を変更」が出ないことを確かめる。オーナーが名前を変えた後に、そのメンバーが再読み込みすると新しい名前が出ることも確かめる
  - 確認結果: 自動で確かめた（利用者と相談して決定）。同じレシピノートのオーナーでないメンバー（テスト用）の設定画面には鉛筆のボタンが出ない。オーナーが名前を変えた後にこのメンバーで開くと、新しい名前が出る
- [x] 3.4 デモモードで、設定画面に「名前を変更」が出ないことを確かめる
  - 確認結果: 自動で確かめた（利用者と相談して決定）。接続設定なしの開発サーバーのデモモードで、設定画面に「みんなのレシピ」が出て、鉛筆のボタンは出ない
