# Spec Delta

## MODIFIED Requirements

### Requirement: プライバシーポリシーと利用規約の表示
すべての動作モードで、ログイン画面からプライバシーポリシーと利用規約を開けなければならない（SHALL）。プライバシーポリシーには、Googleから受け取る情報、その利用目的、保存先、第三者への提供の有無、削除の依頼方法を記載しなければならない（SHALL）。両ページの問い合わせ先は、外部の問い合わせフォームへのリンクで示さなければならず（SHALL）、運営者のメールアドレスを記載してはならない（MUST NOT）。プライバシーポリシーには、問い合わせフォームで受け取る情報とその保存先も記載しなければならない（SHALL）。

#### Scenario: ログイン画面からの表示
- **WHEN** 利用者がログイン画面のプライバシーポリシーまたは利用規約のリンクを選ぶ
- **THEN** 該当するページが表示される

#### Scenario: 直接URLを開く
- **WHEN** 利用者がいずれかの動作モードでプライバシーポリシーまたは利用規約のURLを直接開く
- **THEN** ログインなしで該当するページが表示される

#### Scenario: 問い合わせ先をフォームで示す
- **WHEN** 利用者がいずれかの動作モードで、未ログインのままプライバシーポリシーまたは利用規約の問い合わせ先を見る
- **THEN** 問い合わせフォームへのリンクが表示され、選ぶと新しいタブでフォームが開き、アプリの画面は開いたまま残る

#### Scenario: メールアドレスを載せない
- **WHEN** 利用者がプライバシーポリシーまたは利用規約を開く
- **THEN** ページのどこにも運営者のメールアドレスとメール送信のリンクがない

#### Scenario: 削除の依頼方法
- **WHEN** 利用者がプライバシーポリシーの情報の削除の項目を読む
- **THEN** 問い合わせフォームから削除を依頼する方法が案内されている
