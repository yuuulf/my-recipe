# Proposal

## Why

データベースは1人が複数のレシピノートに所属できる作りになっているが、画面は所属のうち作成日時がいちばん古いレシピノートを1つだけ表示している。そのため、招待リンクで2つ目のレシピノートに参加しても参加は成功するのに画面には出てこず、自分で2つ目のレシピノートを作る入口もない。家族用と友人用のように、複数のレシピノートを切り替えて使えるようにする。

## What Changes

UI の変更が中心。データの保存先として、選んだレシピノートをブラウザ（localStorage）に覚える。データベースのスキーマ、RLS、ルーティング（URL の形）は変えない。

- 開いているレシピノートを切り替えられるようにする
  - PC はサイドバーの「選択中のレシピノート」、スマホはヘッダーのレシピノートの名前から、所属しているレシピノートの一覧を開いて選ぶ
  - スマホのヘッダーは、アプリ名を残し、右端の設定のボタンの場所に開いているレシピノートの名前（切り替えのボタン）を表示する。設定は下のメニューから開ける
  - 切り替えたら、そのレシピノートのレシピ一覧に移る
  - 一覧・検索・追加・設定（メンバー、招待リンク）は、いままでどおり開いているレシピノートが対象
- 選んだレシピノートをブラウザに覚え、次に開いたときもそのレシピノートを開く。覚えたレシピノートがない、またはもう所属していない場合は、所属のうち作成日時がいちばん古いレシピノートを開く（いまと同じ）
- 切り替えの一覧から、新しいレシピノートを作れるようにする（いまのセットアップ画面を使う）。作ったらそのレシピノートを開く
- 招待リンクから参加したら、参加したレシピノートを開く（すでにメンバーの場合も同じ）
- 開いているレシピノートとは別の、所属しているレシピノートのレシピの URL（詳細、編集）を開いたら、そのレシピのレシピノートに切り替えて表示する
- デモモードは固定のレシピノートが1つなので、切り替えは表示しない

対象外:

- 所属しているすべてのレシピノートのレシピをまとめて見る一覧（今回は切り替える形にする）
- どのレシピノートにも入れない個人用のレシピ
- 選んだレシピノートを端末をまたいで覚えること（アカウントに保存しない）
- レシピノートからの退出、レシピノートの削除、名前の変更
- レシピを別のレシピノートに移す、またはコピーすること

影響する動作モード:

- Supabase接続（手元では Supabase Local）: 所属しているレシピノートを切り替えて使える
- デモ: 変わらない（切り替えは表示しない）

## Capabilities

### New Capabilities

- `recipe-note-switching`: 所属している複数のレシピノートの中から開くレシピノートを選ぶこと、選んだレシピノートを覚えること、新しいレシピノートを作ること、招待から参加した後に開くレシピノート、デモモードでの扱いを定める

### Modified Capabilities

- `recipes`: 「レシピの詳細」と「レシピの編集」で、開いているレシピノートとは別の、所属しているレシピノートのレシピの URL を開いたときに、そのレシピノートに切り替えて表示することを追加する
- `auth`: 「認証が必要な画面の保護」で、すでにレシピノートに所属している利用者も、新しいレシピノートを作るためにセットアップ画面を開けることを追加する

## Impact

- 変更: `src/contexts/AppContext.tsx`、`src/contexts/app-context.ts`（所属しているレシピノートの一覧、開いているレシピノート、切り替え、localStorage への記憶）
- 変更: `src/components/Layout/AppShell.tsx`（サイドバーとスマホのヘッダーの切り替え）
- 変更: `src/pages/SetupPage.tsx`（所属している利用者が新しいレシピノートを作る場合の文言と戻り先）、`src/pages/JoinGroupPage.tsx`（参加後に開くレシピノート）
- 変更: `src/pages/RecipeDetailPage.tsx`、`src/pages/RecipeEditPage.tsx`（別のレシピノートのレシピを開いたときの切り替え）
- 追加: 切り替えの一覧の部品（`src/components/` または `src/features/groups/`）
- localStorage: 選んだレシピノートの ID を1つ保存する（新しいキー）
- スキーマ、RLS、マイグレーション、`seed.sql`: 変更なし
- 依存パッケージの追加: なし
