## 3. 確認

- [x] 3.1 `npm run lint` と `npm run build` がエラーなしで通ることを確かめる
- [x] 3.2 Supabase Local で、サンプルのレシピノートに招待で参加し、自分のレシピノートを作って、次を確かめる: 作った後にそのレシピノートが開く、サイドバーとスマホのヘッダーから切り替えられ一覧・検索・追加・設定が切り替えたレシピノートになる、再読み込みしても選んだレシピノートが開く、別のレシピノートのレシピの詳細と編集の URL を開くとそのレシピノートに切り替わる、すでにメンバーのレシピノートの招待リンクから参加するとそのレシピノートが開く、セットアップ画面の「戻る」で元のレシピノートのまま

- [x] 3.4 デモモードで、サイドバーとスマホのヘッダーにデモのレシピノートの名前が出て、切り替えの一覧が開かないことを確かめる
  - 確認結果: 自動で確かめた（利用者と相談して決定）。接続設定なしの開発サーバーのデモモードで、スマホの幅のヘッダーに「My Recipe みんなのレシピ」、PC のサイドバーに「選択中のレシピノート / みんなのレシピ」が出て、どちらにも切り替えのボタン（`aria-haspopup`）がないことを確かめた
