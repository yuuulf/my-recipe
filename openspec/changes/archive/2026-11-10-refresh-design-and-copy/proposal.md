# Proposal

## Why

Tailwind CSS への移行で見た目の値はテーマのトークンにそろったが、デザインそのものは移行前のままになっている。レシピ一覧のカードはスマホで1画面に2件ほどしか見えず、ロゴは仮のアイコンのまま、ログイン画面のアプリ説明は文字だけで目立たない。また、共有の単位が「レシピ帳」「グループ」「ノート」と画面ごとに違う名前で呼ばれているなど、文言の表記がぶれており、重複や飾りだけの文言も残っている。見た目と文言を整え、毎日使いやすくする。

## What Changes

UIだけの変更。データ、API、ルーティングの変更は含まない。仕様（specs）の変更もない。

- レシピ一覧のカード
  - スマホでは1列の横長のリストにする。PCではいままでどおり2列（幅1200px以上で3列）のグリッドに並べる
  - カードの中は3行にする（1行目: 料理名と右端の「>」、2行目: 説明を1行で省略、3行目: 左にタグ（最大4つ）、右に調理時間と人数。タグが収まらないときは折り返す）
  - 右上の矢印をなくす
  - 表示する項目はいまと同じ（料理名、値がある場合は説明、最大4つのタグ、調理時間、人数）
- レシピ一覧の画面
  - 見出しの上のレシピノートの名前と、飾りの文（「いつものごはんを、もっとおいしく、もっと楽しく。」）を削除する
- ロゴとファビコン
  - ロゴを用意された画像（2000px、背景は主色 `#347859`）に差し替える。表示用に縮め、角を6px丸める。アプリ名「My Recipe」の文字は残す
  - サイドバーのロゴの下の「レシピ管理」を削除する
  - 同じ画像から、角を丸めたPNGのファビコンを32px、16px、180px（iPhoneのホーム画面用）で作り、いまの `favicon.svg` と置き換える
- ログイン画面
  - 左上のロゴとアプリ名を、カードの見出しと同じ大きさ（30px、スマホでは28px）にする。招待画面などほかの画面のロゴは変えない
  - アプリ説明の見出しから「My Recipe｜」を外し、「レシピをもっと手軽に」と「管理・共有」の2行にして、2行目を主色で大きくする
  - 主な機能を、薄緑の角丸の四角に入れたアイコン付きで並べる（幅の広いPCは4つ横、それ以外は2×2）。4つ横のときにすべての機能名が1行に収まるよう、アプリ説明の幅を少し広げる。アイコンは本、虫眼鏡、人、Googleの「G」（ログインボタンと同じもの）
  - 画面の下の飾りの文（「あなたの料理の記録を、もっと身近に。」）を削除する（招待画面も同じ）
- 文言
  - 共有の単位の呼び方を、すべての画面で「レシピノート」に統一する（「レシピ帳」「グループ」「ノート」は使わない。例: 「レシピノートをひらく」「レシピノートの設定」「選択中のレシピノート」）
  - 作り方の欄は、見出しを「作り方」、1行ずつの単位を「手順」とする
  - 「参加者」は「メンバー」、バッジの「owner」は「オーナー」、「デモ閲覧中」「デモユーザーは〜できません」は「デモモード」を使った表現にそろえる
  - 重複や飾りだけの文言を削除する（設定画面のカードの小見出し、セットアップ画面の説明の重複、フォームの説明文）
  - フォームの「自分用メモ」を「メモ」にする（レシピはレシピノートのメンバー全員が見られるため）
  - ログイン画面の機能の説明を短くする（「レシピを登録・編集・削除」「料理名やタグから素早く検索」「家族やグループでレシピを共有」「Googleアカウントで簡単にログイン」）。機能名「グループ共有」は「レシピノートの共有」にする
  - 「料理名」はいまのまま変えない
  - プライバシーポリシーと利用規約の「レシピ帳」「グループ」も「レシピノート」にする。意味は変えず、最終更新日もそのままにする

対象外:

- 材料と作り方の並び替え（別の変更 `reorder-recipe-rows` で扱う）
- 招待画面などログイン画面以外のロゴの大きさ
- 仕様（specs）の中の「グループ」という呼び方（内部の呼び方として残す）

影響する動作モード:

- Supabase接続、ローカルプレビュー、デモのすべて。表示と文言の変更だけで、モードごとの動きは変わらない
- デモモードの案内や保存できないときのメッセージは、「デモモード」を使った文言に変わる

## Capabilities

### New Capabilities

なし

### Modified Capabilities

なし（表示と文言だけの変更で、仕様の要件は変わらないため、`.openspec.yaml` に `skip_specs: true` を設定する）

## Impact

- `src/features/recipes/components/RecipeCard.tsx`、`src/pages/RecipeListPage.tsx`: カードと一覧の画面
- `src/components/BrandLockup.tsx`、`src/components/Layout/AppShell.tsx`: ロゴ、サイドバー、文言
- `src/pages/LoginPage.tsx`: ロゴの大きさ、アプリ説明、機能の一覧
- `src/pages/JoinGroupPage.tsx`、`SetupPage.tsx`、`SettingsPage.tsx`、`RecipeCreatePage.tsx`、`RecipeEditPage.tsx`、`src/features/recipes/components/RecipeForm.tsx`: 文言
- `src/pages/PrivacyPolicyPage.tsx`、`TermsPage.tsx`: 呼び方の文言
- `src/contexts/AppContext.tsx`、`src/features/recipes/api/recipes.ts`: 画面に表示されるエラーの文言
- `index.html`: ページのタイトルと説明の「レシピ帳」
- `src/logo.png` を `src/assets/logo.png` に移し、表示用に縮めた画像を用意する
- `public/favicon.svg` を削除し、PNGのファビコンを追加する。`index.html` のファビコンの指定を変える
- スキーマ、RLS、マイグレーション、localStorage のデータ形式: 変更なし
- 依存パッケージの追加: なし
