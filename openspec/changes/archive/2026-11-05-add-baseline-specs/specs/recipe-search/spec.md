# Spec Delta

## Purpose

レシピ一覧画面でのキーワード検索とタグによる絞り込みを定める。すべての動作モードで利用でき、検索の範囲は現在のグループのレシピに限られる。

## ADDED Requirements

### Requirement: キーワード検索
システムは、現在のグループのレシピのうち、料理名、説明、メモ、材料、タグのいずれかにキーワードを含むものを、大文字と小文字を区別せずに返さなければならない（SHALL）。結果は更新日時の新しい順でなければならない（SHALL）。

#### Scenario: 材料での検索
- **WHEN** 料理名に含まれず材料に含まれる語で検索する
- **THEN** そのレシピが結果に含まれる

#### Scenario: 検索対象外の項目
- **WHEN** 作り方または参考URLにのみ含まれる語で検索する
- **THEN** そのレシピは結果に含まれない

#### Scenario: 所属していないグループのレシピ
- **WHEN** 所属していないグループのレシピにのみ含まれる語で検索する
- **THEN** そのレシピは結果に含まれない

#### Scenario: デモモードでの検索
- **WHEN** デモモードで検索する
- **THEN** デモの固定データが同じ検索対象で絞り込まれる

### Requirement: 入力に応じた検索の実行
検索は入力に応じて自動的に実行しなければならない（SHALL）。キーワードが空または空白のみの場合は、グループのすべてのレシピを返さなければならない（SHALL）。

#### Scenario: 入力中の更新
- **WHEN** 利用者が検索欄に入力する
- **THEN** 実行ボタンを押さなくても結果が更新される

#### Scenario: 空白のみの入力
- **WHEN** 検索欄に空白のみを入力する
- **THEN** すべてのレシピが返される

#### Scenario: 検索のクリア
- **WHEN** 入力済みの検索欄でクリアを実行する
- **THEN** 検索欄が空になり、すべてのレシピが表示される

### Requirement: タグによる絞り込み
一覧画面は、「すべて」と定義済みのタグ（肉、魚、野菜、麺、簡単）、および表示中のレシピに含まれるタグを、合計10個までの選択肢として表示しなければならない（SHALL）。タグを選ぶと、そのタグと完全に一致するレシピだけを表示しなければならない（SHALL）。

#### Scenario: タグの選択
- **WHEN** 利用者が「簡単」を選ぶ
- **THEN** タグ `簡単` を持つレシピだけが表示される

#### Scenario: 絞り込みの解除
- **WHEN** 利用者が「すべて」を選ぶ
- **THEN** タグによる絞り込みが解除される

### Requirement: 検索と絞り込みの併用
キーワードとタグが両方指定された場合、両方の条件を満たすレシピだけを表示しなければならない（SHALL）。

#### Scenario: 併用
- **WHEN** キーワードを入力し、タグを選ぶ
- **THEN** キーワードに一致し、かつそのタグを持つレシピだけが表示される

### Requirement: 結果の表示
一覧画面は結果の件数を表示しなければならない（SHALL）。条件を指定した結果が0件の場合は、見つからなかった旨と条件をリセットする操作を表示しなければならない（SHALL）。

#### Scenario: 件数の表示
- **WHEN** 検索または絞り込みの結果が表示される
- **THEN** 表示されたレシピの件数が表示される

#### Scenario: 該当なしからのリセット
- **WHEN** 0件の結果画面で「絞り込みをリセット」を選ぶ
- **THEN** キーワードとタグの条件が解除される
