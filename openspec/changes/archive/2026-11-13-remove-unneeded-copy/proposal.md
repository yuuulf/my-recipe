# Proposal

## Why

画面に、ほかの表示と重なる文言、内容とずれた説明、飾りの英語の小見出しが残っていて、スマホで見たときに大事な情報が下に押し出されている。機能を増やしすぎず、すぐ見られることを優先するため、なくても困らない文言を削る。

## What Changes

UI の文言だけの変更。データ、API、ルーティング、動作は変えない。

削除する文言:

| 画面 | 文言 | 理由 |
|---|---|---|
| レシピノートの設定 | タイトルの上の「設定」 | タイトルと重なる |
| レシピノートの設定 | タイトルの下の「レシピノートを一緒に使うメンバーを管理します。」 | 名前の変更や退出もあり、内容とずれている |
| レシピの詳細 | 料理名の上の「最終更新 〇年〇月〇日」 | 下部（登録者の隣）にも同じ表示がある |
| レシピの詳細 | 料理名の下の「〇ステップ」 | 作り方に番号が付いていて分かる |
| 招待 | 「YOU ARE INVITED」 | 飾りの英語の小見出し |
| 招待 | 参加ボタンの下の「レシピを閲覧・追加」「メンバーと共有」 | すぐ上の説明文と同じ内容 |
| レシピノートの作成（セットアップ） | 「ONE LAST STEP」 | 飾りの英語の小見出し |
| ログイン | 「ログイン後に、あなたのレシピノートを作成できます。」 | 招待で参加する人もいるので正確でない |
| レシピの追加・編集 | 先頭の見出し「料理の記録を残す」 | 編集のときも同じ文言で、なくても分かる |
| サイドバー（PC 幅） | 切り替えの上の「選択中のレシピノート」 | 切り替えのボタンにレシピノートの名前が出る |

残すもの: 調理時間と人数、詳細の下部の「最終更新」、一覧の件数、セットアップの「あとからメンバーを招待できます」、デモモードの注記、メンバーの一覧の「あなた」

影響する動作モード: Supabase 接続とデモの両方で、上の画面の文言が同じように消える。デモだけにある表示は変えない。

## Capabilities

### New Capabilities

なし

### Modified Capabilities

なし（文言だけで、仕様の要件は変わらない。詳細画面の最終更新日は下部に表示が残るので、「レシピの詳細」の要件も満たしたまま。`.openspec.yaml` に `skip_specs: true` を設定する）

## Impact

- 変更: `src/pages/SettingsPage.tsx`、`src/pages/RecipeDetailPage.tsx`、`src/pages/JoinGroupPage.tsx`、`src/pages/SetupPage.tsx`、`src/pages/LoginPage.tsx`、`src/features/recipes/components/RecipeForm.tsx`、`src/components/Layout/AppShell.tsx`、`src/components/styles.ts`（使われなくなる小見出しのクラスを消す）
- データ、マイグレーション、依存パッケージ: 変更なし
