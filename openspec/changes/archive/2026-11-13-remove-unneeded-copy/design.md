# Design

## Context

削除する文言と理由は proposal.md を参照。いまのコード:

- 英語の小見出しと「設定」「最終更新」（料理名の上）は、共通のクラス `eyebrowClassName`（11px、太字、字間を広げた薄い文字）で表示している。使っているのは、今回消す5か所（設定、詳細、招待、セットアップ、サイドバー）だけ
- その下の見出しは、小見出しがある前提で上の余白を持っている（設定の `pageTitleClassName` の `mt-2.25`、詳細の料理名の `mt-2.75`、招待とセットアップの見出しの `mt-3`）
- レシピ一覧のタイトルは小見出しなしで `pageTitleClassName` を使っている
- レシピのフォームの「料理の記録を残す」は、フォームでただ1つの `h1`

## Goals / Non-Goals

**Goals:**

- 文言を消した後に、余白が不自然に空かないようにする
- 見出しの構造（画面ごとの `h1`）を保つ

**Non-Goals:**

- 残す文言の言い回しの変更や、文言の追加
- レイアウトの組み直し（消した分を詰める以外）

## Decisions

### 1. 小見出しを消したら、下の見出しの上の余白も詰める

- **設定**: 「設定」を消す。`pageTitleClassName` の `mt-2.25` は、一覧のタイトルと同じ見た目になるので、そのまま使う（一覧と設定のタイトルの位置がそろう）
- **詳細**: 「最終更新」を消し、料理名の `mt-2.75` を外す
- **招待**: 「YOU ARE INVITED」を消し、見出しの `mt-3` を外す
- **セットアップ**: 「ONE LAST STEP」を消し、見出しの `mt-3` を外す（アイコンの下の余白 `mb-5.75` で離れる）
- **サイドバー**: 「選択中のレシピノート」を消す。切り替えのボタンの上の余白は、いまの `mt-10.5` のまま

消した後に `eyebrowClassName` を使う場所がなくなるので、`styles.ts` から消す。

### 2. フォームの見出しは、見た目からだけ消す

「料理の記録を残す」を消すと、追加・編集画面に `h1` がなくなり、読み上げソフトで画面の見出しが分からなくなる。見た目の見出しは消し、代わりに `sr-only`（画面には出ないが読み上げられる）の `h1` を置く。文言は、追加のときは「レシピを追加」、編集のときは「レシピを編集」にする。`RecipeForm` には、どちらの画面かを表す `title` の prop を足し、追加・編集画面から渡す。

見た目の見出しを消すと、最初の区切りのアイコンだけが「料理名」の上に残って間が空く。そこで「料理名」のラベルを、材料・作り方の見出しと同じ位置（PC ではアイコンの横、スマホではアイコンの下）に置き、文字の大きさと太さも材料・作り方の見出しと同じ（20px、太字）にする（利用者と相談して決定）。

見出しを消すだけにする案は、画面の `h1` がなくなるので採らない。見た目の見出しを「レシピを追加／編集」に変える案は、文言を足すことになり今回の目的から外れるので採らない。

### 3. 詳細画面の「〇ステップ」

調理時間と人数が両方ないレシピでは、料理名の下の行（時間・人数・ステップ）が空になる。その行は、時間か人数があるときだけ出す（空の余白を残さない）。

### 4. 招待画面の機能の表示

参加ボタンの下の2つの表示を、包んでいる要素ごと消す。ボタンの下の余白は、カードの下の余白で足りる。

### 5. ログイン画面

「はじめて使う方へ」の区切りの下の1文を消す。区切りの直後に「デモのレシピを見る」が来るので、そのリンクの上に、消した文の余白の分（`mt-3.25`）を移す。

### 6. テスト

- 文言を探しているテストがないことを確かめる（いまは `SetupPage` の見出しのテストだけで、見出しの文言は変えない）
- `RecipeForm` のテストに、`title` が読み上げ用の見出しとして出ることのテストを足す
- 画面は、スマホ幅（390px）と PC 幅で、消した後の余白を見て確かめる

## Risks / Trade-offs

- [Risk] 詳細画面の上部から更新日がなくなり、いつのレシピか一目で分からなくなる → 下部に表示が残る。必要なら後で戻せる
- [Risk] サイドバーで、切り替えのボタンが何のボタンか分かりにくくなる → ボタンにレシピノートの名前と開く印（下向きの矢印）があり、読み上げでは「レシピノートを切り替える（いまは〇〇）」と読まれる
