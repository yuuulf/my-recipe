## MODIFIED Requirements

### Requirement: キーワード検索
システムは、現在のグループのレシピのうち、料理名、説明、メモ、材料、タグのいずれかにキーワードを含むものを、大文字と小文字を区別せずに返さなければならない（SHALL）。結果は更新日時の新しい順でなければならない（SHALL）。キーワードはすべての動作モードで文字どおりに扱わなければならず（SHALL）、`%` や `_` などの文字をワイルドカードとして扱ってはならない（MUST NOT）。

#### Scenario: 材料での検索
- **WHEN** 料理名に含まれず材料に含まれる語で検索する
- **THEN** そのレシピが結果に含まれる

#### Scenario: 検索対象外の項目
- **WHEN** 作り方または参考URLにのみ含まれる語で検索する
- **THEN** そのレシピは結果に含まれない

#### Scenario: 所属していないグループのレシピ
- **WHEN** 所属していないグループのレシピにのみ含まれる語で検索する
- **THEN** そのレシピは結果に含まれない

#### Scenario: デモモードでの検索
- **WHEN** デモモードで検索する
- **THEN** デモの固定データが同じ検索対象で絞り込まれる

#### Scenario: 記号を含むキーワード
- **WHEN** `_` または `%` を含むキーワードで検索する
- **THEN** 検索対象の項目にその文字をそのまま含むレシピだけが結果に含まれる
