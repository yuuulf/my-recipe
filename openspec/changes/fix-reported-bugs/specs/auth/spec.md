## MODIFIED Requirements

### Requirement: セッションの維持
ログイン状態は、ページの再読み込みやブラウザの再起動の後も、ログアウトまたはセッションの失効まで維持しなければならない（SHALL）。ログインのトークンが自動で更新されても、表示中の画面を作り直したり、入力中の内容を失わせたりしてはならない（MUST NOT）。

#### Scenario: 再読み込み
- **WHEN** ログイン済みの利用者がページを再読み込みする
- **THEN** ログインし直さずに利用を続けられる

#### Scenario: トークンの自動更新
- **WHEN** 利用者がレシピのフォームに入力している間に、ログインのトークンが自動で更新される
- **THEN** 画面は読み込みの表示に替わらず、入力した内容はそのまま残る
