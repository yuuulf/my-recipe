# my-recipe Clean Utility デザイン実装プラン

## 1. 概要

`my-recipe` の現在の機能を変更せず、UI/UXのみを **Clean Utility** デザインへ変更する。

今回の変更では、以下は行わない。

- 新機能の追加
- Supabaseのテーブル変更
- API仕様の変更
- CRUD処理の変更
- 検索ロジックの変更
- タグ絞り込みロジックの変更
- ルーティングの変更
- 認証・グループ機能の仕様変更

既存の機能・データ構造を維持し、主にCSSと既存コンポーネントのレイアウトを変更する。

---

# 2. デザインコンセプト

## Clean Utility

装飾を抑え、情報の整理と使いやすさを重視したデザインにする。

料理中やスマートフォンからでも情報を素早く確認できることを重視する。

### デザイン方針

- 白をベースとした明るいUI
- メインカラーは深いグリーン
- オレンジ中心の配色からグリーン中心へ変更
- serif系フォントからsans-serif中心へ変更
- 小さすぎる文字サイズを改善
- カードの装飾を減らす
- 薄いborderとshadowを使用
- 適度な余白を確保
- PCでは管理アプリ風
- モバイルではコンパクトなリスト型

---

# 3. 今回追加しない機能

デザイン参考画像には存在するが、現在の `my-recipe` に実装されていない以下の要素は追加しない。

- お気に入り
- お気に入り一覧
- タグ管理画面
- ノート機能
- 並び替え
- グリッド / リスト表示切り替え
- カテゴリ別件数表示
- 料理画像
- カテゴリ専用ナビゲーション
- PC用検索ショートカット
- 新しいフィルター機能

既存機能のみを利用する。

## カラー

```css
:root {
  --primary: #347859;
  --primary-hover: #286347;
  --primary-soft: #eaf3ed;

  --background: #f5f7f6;
  --surface: #ffffff;
  --surface-muted: #f8faf9;

  --text: #1f2925;
  --text-secondary: #68746e;
  --text-muted: #98a29d;

  --border: #e2e7e4;
  --border-strong: #d5ddd8;

  --danger: #c85d4b;

  --shadow-sm: 0 1px 3px rgba(20, 35, 27, 0.05);
  --shadow-md: 0 6px 20px rgba(20, 35, 27, 0.07);
}
```

## フォント

外部フォントの追加は行わず、システムフォントを利用する。

```css
font-family:
  Inter,
  "Noto Sans JP",
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  sans-serif;
```

## 文字サイズ目安

| 用途 | サイズ |
|---|---:|
| ページタイトル | 26〜30px |
| セクションタイトル | 18〜20px |
| カードタイトル | 16〜17px |
| 本文 | 14〜15px |
| 補助情報 | 12〜13px |
| タグ | 12px |

現在使用している9〜11px前後の小さい文字は可能な範囲で12px以上へ変更する。

## 角丸

```css
--radius-sm: 6px;
--radius-md: 8px;
--radius-lg: 10px;
```

過度に丸いカードは避ける。

# 27. 実装時のルール

今回のデザイン変更では以下を守る。

1. 新機能を追加しない
2. DBを変更しない
3. Supabase関連処理を変更しない
4. CRUDロジックを変更しない
5. 検索ロジックを変更しない
6. タグ絞り込みロジックを変更しない
7. 現在存在しない情報をUIへ追加しない
8. 画像機能を追加しない
9. デザイン変更のためだけに不要なライブラリを追加しない
10. CSSで対応可能な部分はCSSを優先する
11. PC / Mobileの既存機能を維持する
12. デザイン変更後に必ず既存機能を再確認する
